# playwright-ecommerce-testing
My Playwright E-commerce Testing Project

I've been working on strengthening my QA and test automation skills, and I've completed another hands-on project using Playwright and JavaScript

For this project, I tested the SauceDemo e-commerce application and automated important user workflows.

What I worked on
- Login testing with valid and invalid credentials
- Cart operations, including adding, removing and verifying multiple products
- Checkout workflow and form validation
- Product sorting in different orders
- Cross-browser testing using Chromium, Firefox and WebKit

One of the most valuable parts was investigating an unexpected sorting failure with the problem_user account. I used Playwright's assertion output and page snapshots to identify and document the behaviour.

Key things I learned
- Writing automated test cases
- Using Playwright locators and assertions
- Debugging test failures
- Performing cross-browser testing
- Identifying and documenting defects

This project helped me understand that QA is not just about checking whether a test passes. It's also about investigating unexpected behaviour and providing evidence of defects.

I'm continuing to improve my testing and automation skills through practical projects.
